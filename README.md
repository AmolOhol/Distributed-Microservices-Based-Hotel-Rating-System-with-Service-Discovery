# Distributed-Microservices-Based-Hotel-Rating-System
This project is a high-availability, scalable microservices architecture designed to manage user-generated ratings for hotels. By integrating Feign Client for declarative REST communication, the system ensures seamless interoperability between loosely coupled services.
This architecture provides a fully decoupled, production-ready system where services are not only secured and resilient but also dynamically discoverable. By integrating Netflix Eureka, the system gains the ability to scale horizontally without manual configuration updates.
